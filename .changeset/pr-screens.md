A pull request `/inbox pr` shows is now a screen to read alone: nothing on it changes the pull request or what goes with the next prompt, so a key pressed by mistake does no harm. Where it stands is a card at the top, each part in its mark's color and the border in the most pressing one's (purple merged, grey closed or a draft); under a rule each come its CI, its description, and its reviews and comments, a card each, colored by what a review says (approved green, changes requested red), its threads of line comments in it (open yellow, resolved grey), what was written drawn as Markdown, a long body or a thread's replies folded behind **▸ N more lines / replies**. **Hand to Claude…** (`c`) goes to the screen that chooses what to attach, as the pane listed it before; **Actions…** (`o`) to the one that merges, drafts, approves or closes it (under "Sent to GitHub", each still confirmed in its own pane) or watches it (under "Notices"); **Back** (`b`) comes back. Once what was confirmed is done, the pane goes back to where it stands. The list heads each group on a rule, each part of where a pull request stands in its mark's color.

`/inbox pr` で開いた PR を、見るだけの画面にしました。PR を変えるものも、次のプロンプトに添えるものを変えるものもないので、キーを打ち間違えても何も起きません。一番上のカードに状態を出し、項目ごとに記号の色で、枠は一番急ぐ項目の色にします（マージ済みは紫、クローズ済みと下書きは灰色）。その下に仕切りを置いて、CI・説明文・レビューとコメントをカードに分けて出します。レビューのカードは何をしたかで色を変え（承認は緑、変更依頼は赤）、その行コメントのスレッドをカードの中に並べ（未解決は黄、解決済みは灰色）、本文は Markdown で出します。長い本文とスレッドの返信は **▸ 続きN行・返信N件** で開きます。**Claude に渡す…**（`c`）で、これまでと同じ一覧から添付するものを選ぶ画面に、**操作…**（`o`）で、マージ・下書きの切り替え・承認・クローズ（「GitHub に送るもの」。これまでどおり確かめるペインを開きます）と通知（「通知」）の画面に移り、**戻る**（`b`）で戻ります。確かめたものを実行し終えると、状態の画面に戻ります。一覧は、グループの見出しを仕切りにし、状態を項目ごとに記号の色で出します。
