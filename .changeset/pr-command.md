Pull requests have one command, `/inbox pr`. `/inbox pr` lists them a group each, each once: this branch's, yours and those asked of you, those watched, those `/inbox log` keeps notices of (with how many and how long ago the newest came), and the open ones of this repository and those in registered repositories you are involved in, each with where it stands. `/inbox pr 12` (or a row pressed) shows one: where it stands with the reviewers named, buttons to watch, merge, draft, approve or close it (each confirmed in a pane as before), and its description, CI, reviews, threads and comments to attach for Claude, as `/inbox pick` listed them. `/inbox pr [PR] show|merge|close|draft|approve|unapprove|watch|unwatch` does one of those at once, to this branch's pull request where none is named. `/inbox pick`, `/inbox watch`, `/inbox merge`, `/inbox close`, `/inbox draft`, `/inbox approve` and `/inbox unapprove` now say where they went. `/inbox log` narrowed to one repository lists its notices newest first again, not by pull request. `/inbox` alone goes on to each setting as it is now, with how to change it, and the commands (`/inbox status` says where things stand alone); the counts of your pull requests, those asked of you and those watched share one line pointing to `/inbox pr`, and where notices show is said only when it is another window.

PR に対するコマンドを `/inbox pr` 1つにまとめました。`/inbox pr` で、今のブランチの PR・自分の PR とレビュー依頼・通知している PR・`/inbox log` に通知が残っている PR（件数と最新が何分前か付き）・このリポジトリと登録したリポジトリで自分が関わっている開いた PR を、グループに分けて1回ずつ、それぞれの状態と一緒に出します。`/inbox pr 12`（または一覧で押した PR）で PR を開くと、レビューした人・待っている人の名前を添えた状態、通知・マージ・下書き・承認・クローズのボタン（これまでどおりペインで確かめてから行います）、`/inbox pick` と同じ説明文・CI・レビュー・スレッド・コメントの一覧が出て、選んで Claude に添付できます。`/inbox pr [PR] show|merge|close|draft|approve|unapprove|watch|unwatch` でその操作をすぐに行えます（PR を省くと今のブランチの PR）。`/inbox pick`・`/inbox watch`・`/inbox merge`・`/inbox close`・`/inbox draft`・`/inbox approve`・`/inbox unapprove` は、移った先を案内します。1つのリポジトリに絞り込んだ `/inbox log` は、PR ごとにまとめず、また新しい順に並べるようにしました。`/inbox` だけを打つと、状態に続けて設定の今の値と変え方、コマンドの一覧を出すようにしました（状態だけなら `/inbox status`）。自分の PR・レビュー依頼・通知する PR の件数は1行にまとめて `/inbox pr` を案内し、通知を出す窓は別の窓のときだけ書きます。
