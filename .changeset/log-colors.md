`/inbox log` draws the repository's short name in color and links only what was done, not the whole line. `/inbox repo` tells how long ago each repository's last event happened, and a tray line under the prompt keeps telling it for every registered repository (turn it off with "GitHub: Tray" in /config).

`/inbox log` でリポジトリの短い名前に色を付け、リンクを行全体から「何をしたか」の部分だけにしました。`/inbox repo` で、リポジトリごとに最後のイベントが何分前かを出します。プロンプトの下のトレイにも常に出します（/config の「GitHub: Tray」で消せます）。
