`/inbox log` now lists the notices of every window, closed ones too, each line a link to it on GitHub with when it happened beside it. What came while no window was open is listed by the next window at its first check, with one line saying how many.

`/inbox log` が窓（セッション）をまたいで通知を出すようにしました。閉じた窓の通知も見られます。各行は GitHub へのリンクになり、いつのことかを添えます。どの窓も開いていなかったあいだの更新は、次に開いた窓が最初の確認で一覧に入れ、件数を知らせます。
